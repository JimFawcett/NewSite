Synopsis:
This page describes LLM agents: what they consist of, and what they do well and badly.
  • An agent runs autonomously from an initial prompt and a stopping goal the user sets.
  • When it runs well, it gets a lot done without the user's immediate attention.
  • When it does not, it creates junk output and deletes good content, so developers test agents in a sandbox first.
  • Bad actors can use swarms of agents for attacks and misinformation.

1.  Agent Architecture

Agents appear often in the news. Understanding the concept matters because agents play a large role in both the benefits and the liabilities of LLM AIs. In Fig 1, the user hands the agent a goal and gets results back. Inside the agent, four parts cooperate:
  • A planner breaks the goal into steps.
  • A tool orchestrator selects and uses tools.
  • Memory keeps context and history.
  • A controller iterates until the agent meets the goal.
 The agent prompts the LLM for reasoning and plans, and it reads files, searches the web, and calls applications and databases for data. The memory in Fig 1 belongs to the agent, not the model. The model keeps nothing between requests, so the agent carries context and history forward and resends them on every call, per Context Section 1. 2.  Takeaways

  1. Agents run autonomously from an initial prompt and a stopping goal the user sets.
  2. The good news: when an agent runs well, it gets a lot done without the user's immediate attention.
  3. The bad news: when an agent does not operate as the user intends, it can create a lot of junk output and delete good content. That is sometimes difficult to prevent, because the agent infers much of what it does from the meaning of the request. Developers therefore test in a sandbox until everything works, then deploy to working repositories.
  4. The really bad news: bad actors can create swarms of agents to attack banking security and civilian infrastructure control, and to post misinformation on social media.
Item 3 is the gap the Spec-Driven process closes. An agent that infers meaning from an ambiguous request fills the gap with a guess; the Constitution treats an ambiguous specification as a question instead.
